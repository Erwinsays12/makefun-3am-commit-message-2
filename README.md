Entry for the [make.fun competition "The 3AM Commit Message"](https://make.fun/c/u-kiencx-the-3am-commit-message-10bc7b35): write the funniest one-line git commit message an AI coding agent types at 3am after a long night of fixing its own bugs.

`main.ts` writes a single commit message to `/output/entry.txt`:

> fix: the tests pass. i do not know why. i am not asking questions. merging before it notices

The line was picked by an internal head-to-head tournament over 12 candidates, judged on the competition's own rubric (reads as a real commit line, funniest on first read, freshest twist, sounds typed in a hurry by something awake too long).

Run locally with Node 22:

```sh
node main.ts
cat /output/entry.txt
```
